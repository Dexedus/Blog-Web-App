# Project Description
This is a blog web application that allows any user to create, read, update and delete posts. I used node.js, express.js for the backend. I used EJS for the templating and I used Axios to handle the requests to my API. New data is held temporarily and will not persist as no database is used here. This is simply a poject to showcase my skills in creating a blog app with a simple and effective UI, as well as showing my ability to make a custom API and rquesting data from that API to make changes to the site.
